Observed series: daily confirmed cases per 100,000 residents, shown as a 7-day moving average. SIR series: simulated new infections per 100,000 per day. These are different measures and the SIR parameters are not fitted to the observed series. Source: JHU CSSE COVID-19 repository (archived March 10, 2023).

Model note: dS/dt = −βSI/N; dI/dt = βSI/N − γI; dR/dt = γI. Assumptions: homogeneous mixing, constant population, fixed rates per scenario, and no explicit age structure, vaccination, behavior changes, or exposed/asymptomatic compartments. Euler integration uses a 1-day step. This is an educational simulation, not a forecasting tool.
